# B. 项目体验档案

## 1. 核心产品承诺

Copilot App 在 KnowMe 生态中的定位是：

local-first 的个人知识引擎；

专业知识工作台；

知识存储、检索、RAG、知识图谱和执行能力的承载产品；

可被 KnowMe 复用的知识管理与执行基础设施。

Copilot 不是整个生态的终极中枢，也不应退化为普通聊天机器人、普通笔记 App 或知识图谱 Demo。

用户应感受到：

我的资料不是被简单存放，而是被可信地组织、调用、核验，并帮助我形成判断和下一步行动。

## 2. 目标用户视角

Blind User Reviewer 应扮演：

一位拥有多份项目资料、笔记和决策记录，希望在本地安全地组织知识，并让 AI 基于自己的资料回答和推进工作的知识工作者。

不得提前告诉它“这是 local-first RAG 工作台”。

## 3. 项目专项用户旅程

### C1：首次启动与价值理解

启动真实 Electron 候选；

查看首屏、空状态、导航和主入口；

判断用户是否在 30 秒内理解产品价值；

判断它看起来是完整知识工作台，还是功能拼装集合。

### C2：建立自己的知识

至少完成：

创建一条真实笔记；

导入一个真实 Markdown、PDF 或当前支持文件；

查看导入反馈；

查看摘要、标签、关系或其他组织结果。

判断：

用户是否知道内容去了哪里；

导入是“上传文件”还是“进入知识系统”；

用户能否检查与纠正。

### C3：基于个人知识问答

提出一个必须依赖已导入资料才能回答的问题。

验证：

回答是否真正使用个人知识；

来源是否可见、可点击、可核对；

无来源时是否诚实；

模型常识是否与个人资料清楚区分；

用户是否理解为什么得到这个答案。

### C4：知识组织和图谱的实际价值

体验：

搜索；

标签；

双向链接；

关联笔记；

知识图谱；

节点详情；

筛选与导航。

判断：

这些能力是否帮助用户理解和定位知识；

图谱是否只是视觉展示；

用户是否知道点击后能做什么。

### C5：从知识走向执行

按当前范围完成至少一项：

从回答生成 Todo；

加入日程；

保存为计划；

形成下一步行动；

将回答转化为可继续工作的对象。

判断：

Copilot 是否把知识变成工作推进力，而不只是生成一段文字。

不在当前范围时标 N/A。

### C6：退出、重启与 local-first 连续性

完全关闭 App；

重启；

检查笔记、来源、问答上下文、Todo、日程和设置；

再次基于此前资料提问；

在可控条件下断网，验证本地核心能力。

### C7：模型、配置和安全边界

检查：

Provider 配置；

凭据提示；

本地与云边界；

Backup / Remote 是否默认关闭或明确说明；

API key 是否可能暴露在渲染页、日志或笔记中；

用户是否理解哪些操作会离开本机。

### C8：失败闭合与数据信任

至少测试：

模型不可用；

文件损坏；

空知识库提问；

导入失败；

无网络；

数据库或索引异常。

判断：

是否虚假成功；

本地数据是否仍安全；

用户是否知道如何恢复；

错误是否破坏“自己的知识可依赖”的信任。

## 4. 项目专项评分

每项 1–5 分，N/A 不计入：

首次价值理解；

“知识属于我”的感受；

local-first 可信感；

来源与回答可核验性；

知识组织的实际价值；

知识到行动的转化能力；

信息架构和交互一致性；

产品差异化；

失败状态中的信任感；

与 KnowMe 生态定位的一致性；

预测持续使用阻力。

## 5. Copilot 专项阻塞条件

以下任一成立，通常不得判 EXPERIENCE_READY：

回答声称基于个人知识，但没有真实来源；

无来源内容被呈现为可靠事实；

本地数据在重启后丢失或不可恢复；

核心能力硬依赖云端，却仍宣传 local-first；

用户无法判断哪些数据离开本机；

知识图谱只有视觉效果，没有可用价值；

回答无法转化为任何可继续工作的对象，但当前版本宣称执行工作台；

错误状态可能损坏或覆盖用户知识。

可增加：

BLOCKED_SOURCE_TRUST

BLOCKED_LOCAL_FIRST_BOUNDARY

## 6. Copilot Human Owner Gate

所有 P0 关闭后，生成十分钟人工脚本：

导入一份 Owner 熟悉的真实资料；

提一个只能根据该资料回答的问题；

检查并打开来源；

修改或补充一条资料；

再次提问并观察变化；

把回答转成一个下一步行动；

完全退出重启；

Owner 回答：

我是否感觉这是“我的知识助手”，而不是一个通用聊天机器人？

AI 只能输出 HUMAN_OWNER_GATE_REQUIRED。

# C. 本轮启动指令

首次安装完成后：

完整读取 Core 和本项目 Profile；

只通过真实 Electron UI 评审；

判断评审模式；

优先使用隔离 Blind User Reviewer；

根据上一轮报告决定 Focused Retest 或完整评审；

不修改产品代码。
