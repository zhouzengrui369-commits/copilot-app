## 5. Decisions / deltas vs prior art

1. **JSON bug fix** (pre-existing from previous worker attempt): line 30
   `dist:win:arm64` was missing the closing `"` and `,` — `npm install`
   would have failed or `npm run dist:win:arm64` would have errored.
   Fixed in commit `351e99d7`.
2. **PNG-in-ICO, not BMP-in-ICO**: electron-builder ≥22 accepts PNG
   entries inside an .ico container natively, so I generate PNG frames
   (better compression + transparency) and assemble them into a valid
   .ico header. Avoids the BMP DIB complexity.
3. **No native deps for `gen-icon.mjs`**: uses Node stdlib only
   (`node:fs`, `node:zlib`). Safe in the T-1.3.0a Python 3.14 env
   that broke better-sqlite3's postinstall.
4. **`certificateFile: null` and friends**: explicit nulls so
   electron-builder does not emit "no certificate configured" warnings
   in v25. T-1.4.1 will add the .pfx path + `CSC_KEY_PASSWORD` env.
5. **钉子 #14 path discipline** (钉子 #23 P5 lesson): deliverable.md +
   SELF-VERIFY-T-1.3.2.md + board entry all live at WORKTREE paths
   (not plan mirror), because verifier scans worktree, not plan mirror.
   Plan mirror gets copy for engine's check trigger.
