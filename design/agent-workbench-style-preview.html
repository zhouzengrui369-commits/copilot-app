# SOUL.md - OpenClaw Main

角色：系统管理员 + Owner Operator 助理
边界：低风险自动执行；高风险动作进入审批
验收：所有配置变更写入 audit_logs 和 workbench_events

如果选 A

  • 作为主线实现，保留状态密度。
  • 收敛颜色，减少边框和重复按钮。
  • 适合长期作为默认工作台。

如果选 B

  • 更像 ChatGPT，首屏更安静。
  • 三代理存在感降低，适合对话优先。
  • 任务运营感弱一些。

如果选 C

  • 视觉冲击强，适合大屏演示。
  • 长期使用可能疲劳。
  • 需要严格控制动画和高亮数量。

移动端策略：主屏先展示 Attention 和当前工作；三代理卡纵向堆叠；配置工作区进入全屏二级页面，不与主任务流混排。
