2D 知识图谱应该怎样帮助我查看知识？

2D 视图应是 MOC 阅读界面，而不是节点网络。它先给出主题摘要和推荐阅读路径，再按领域展示相关笔记、实体、关系和反向引用。

节点图保留给后续 3D 探索，不进入当前 MVP 的 2D 主视图。

把这个结论转成今天的下一步。

建议先完成 MOC 原型验收，再更新 UI 实施合同；语音录入合并到快速笔记，AI 问答使用不占主布局的悬浮折叠窗，完整历史与深度追问留在独立对话页。
