## 1. Goal

为 copilot app 创建 **Knowledge Graph (KG) 构建器**：从本地 KB 笔记自动抽取 entity / relation / tag / summary，生成结构化知识图谱，存本地 SQLite（**不在云**），支持增量更新。这是 Sprint 1.3 RAG 检索的基石。

验收信号（plan.md §2.2 T-1.2.1）：
- 录入 20 条笔记 → KG 自动生成 **≥ 30 节点 ≥ 50 边**
- 增量更新 < 2s（新增 1 条笔记 → KG 自动更新）
- 100% 本地（决策红线 2）

## 5. Schema (v0 · freeze at Sprint 1.2 末尾)

```sql
-- KG nodes (entities)
CREATE TABLE kg_nodes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  entity_id TEXT UNIQUE NOT NULL,    -- LLM 生成的稳定 ID (e.g., "person_张三")
  type TEXT NOT NULL,                -- person / org / concept / event / place / ...
  name TEXT NOT NULL,
  aliases TEXT,                      -- JSON array
  summary TEXT,                      -- LLM 生成的实体摘要
  confidence REAL,                   -- 0-1
  source_notes TEXT,                 -- JSON array of note paths
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
CREATE INDEX idx_kg_nodes_type ON kg_nodes(type);
CREATE INDEX idx_kg_nodes_name ON kg_nodes(name);

-- KG edges (relations)
CREATE TABLE kg_edges (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  from_entity_id TEXT NOT NULL,
  to_entity_id TEXT NOT NULL,
  rel TEXT NOT NULL,                 -- 关系类型 (e.g., "works_at", "knows", "related_to")
  weight REAL,                       -- 0-1
  evidence TEXT,                     -- JSON array of source note paths
  created_at INTEGER NOT NULL,
  PRIMARY KEY (from_entity_id, to_entity_id, rel)
);
CREATE INDEX idx_kg_edges_from ON kg_edges(from_entity_id);
CREATE INDEX idx_kg_edges_to ON kg_edges(to_entity_id);

-- Note → Entity 映射（反向索引）
CREATE TABLE note_entities (
  note_path TEXT NOT NULL,
  entity_id TEXT NOT NULL,
  PRIMARY KEY (note_path, entity_id)
);

-- Tags（独立存储，支持 Sprint 1.3 RAG 召回）
CREATE TABLE kg_tags (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT UNIQUE NOT NULL,
  note_count INTEGER DEFAULT 0,
  created_at INTEGER NOT NULL
);
```

**Schema freeze 必做**：Sprint 1.2 末尾写 `packages/kg/SCHEMA-FROZEN-1.2.md`，记录所有 table + index + 字段含义，钉子 #14 升级到 plan-level。
