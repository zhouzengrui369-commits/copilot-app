## 5. Wave 拆分

### wave 1 (≤25min): CRUD + 列表 + 日历视图
- packages/kb 新增 `todos` 表（migration v1）
- packages/kb/src/api/todo.ts（createTodo / readTodo / updateTodo / deleteTodo / listTodos）
- TodoList 组件（列表视图）
- CalendarView 组件（FullCalendar 集成，月/周/日切换）
- TodoEditor 组件（CRUD 表单）
- useScheduleData hook
- 单测：5 个 case（CRUD + 列表 + 日历）
- 截图：列表视图 + 日历视图（≥ 2 张）

### wave 2 (≤25min): 提醒 + 笔记关联
- ReminderManager（Notification API + Electron Notification）
- 权限优雅降级（拒绝 → UI 弹窗 + 列表高亮，不静默）
- NoteLink 组件（点击待办跳关联笔记）
- 提醒测试：加 1 个 1min 后提醒的待办 → 收通知
- 单测：3 个 case（提醒 / 权限降级 / 笔记关联）
- 截图：提醒通知 + 笔记跳转（≥ 1 张）

**超时处理**：wave 1 失败 → 整个 T-1.2.5 失败；wave 2 失败 → CRUD 部分保留 + 提醒标 PARTIAL。
