## 5. Wave 拆分

### wave 1 (≤25min): 端侧 WebSpeech + UI
- 集成 WebSpeech API（webkitSpeechRecognition）
- 实现 RecorderButton + Waveform UI
- 实现 WebSpeechProvider（端侧转写）
- 单测：3 个 case（开始/停止/转写结果）
- 截图：录音 UI + 波形（≥ 1 张）

### wave 2 (≤25min): 云端 ASR 兜底 + 入库
- 集成腾讯云 ASR（v5 已有，复用 cloud server proxy）
- 实现 CloudAsrProvider（端侧失败自动 fallback）
- 实现 useTranscriber hook（端侧/云端自动切换）
- 实现转写后入库 packages/kb
- 截图：端侧失败 → 云端 fallback 提示（≥ 1 张）+ 入库结果（≥ 1 张）

**超时处理**：wave 1 失败 → 整个 T-1.2.4 失败；wave 2 失败 → 端侧部分保留 + 云端兜底标 PARTIAL。
