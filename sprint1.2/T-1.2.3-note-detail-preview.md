| MD 解析 | react-markdown + remark-gfm | GitHub Flavored Markdown |

## 8. 风险

| # | 风险 | 缓解 |
|---|------|------|
| R1 | XSS 漏洞（用户笔记含 `<script>`） | rehype-sanitize 必用 + 单测覆盖 |
| R2 | 双链 `[[note_path]]` 解析路径冲突 | 用 KB 的 `path` 字段做 ID，不依赖文件名 |
| R3 | 反向引用性能（笔记多时慢） | packages/kg query 加索引（kg_edges.from_entity_id） |
