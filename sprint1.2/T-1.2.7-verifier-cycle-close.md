## 1. Goal

为 Sprint 1.2 提供 **cycle-close audit 机制**：每个 cycle 结束后自动触发 verifier 做 spot-check 30% + 关键决策审计，写 audit 报告到 `sprint1.2/audit/cycle-<N>-audit.md`。

验收信号（plan.md §2.2 钉子 #15）：
- 每 cycle 一份 audit 报告
- spot-check 30% 真实跑 6 件套
- 关键决策有审计（钉子 #14 #15 + 决策红线）
- VERDICT 行必填
- 钉子 #14 3 件齐

---

## 2. Scope（Allowed）

新建/修改 文件**仅限**：
- `sprint1.2/audit/cycle-<N>-audit.md`（每 cycle 一份，verifier 写）

## 3. Forbidden

- ❌ **不**改 worker 任务的代码 / docs

## 4. 工作内容（5-10min/cycle · 30min cap 必看）

### 4.1 spot-check 30%（核心）

本 cycle 内完成的 worker 任务（plan.yaml 输出），随机抽 30%（向上取整，最少 1 个，最多 3 个），跑 6 件套：

```bash
# 1. commit 真实
cd /Users/njx/openclaw/copilot.wt-T1XX/wt-T1XX
git log <branch> --oneline -3

# 2. deliverable 存在 + VERDICT
test -f outputs/<task_id>/deliverable.md
grep "VERDICT" outputs/<task_id>/deliverable.md

# 3. 截图真实（PNG header 验证，非 fabricated）
file screenshots/<task_id>/*.png  # 应输出 "PNG image data"

# 4. jest suite 数对得上
cd <package>
npx jest --listTests | wc -l  # 应 ≥ producer 声明数

# 5. typecheck clean
cd <repo root>
npm run check --workspaces  # exit 0

# 6. deliverable 文件齐
ls outputs/<task_id>/  # 应含 deliverable.md + SELF-VERIFY
```

### 4.2 关键决策审计（必跑）

| 项 | 验证方式 |

| 钉子 #15 author_role | plan.yaml metadata 含 author_role + dispatch log 含 worker/verifier/PM 标识 |

## 8. 钉子 #15 落地意义

- **避免一坨 commit 不知谁做的**（verifier 视角 5 commits 5 分钟批处理的反思）
- **author_role 标识**让 audit 报告有"谁 dispatch / 谁 verify / 谁 approve"链路
- **cycle-close audit** 让 Sprint 1.2+ 有 plan-level 监督，不只靠 producer self-report
- **写死的 cycle 触发**避免 verifier 偷懒不跑（钉子 #14 教训）
