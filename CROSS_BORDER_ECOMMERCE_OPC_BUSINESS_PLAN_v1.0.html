CHAPTER 01

项目概述

1.1 一句话定义

AI OPC 跨境电商 = 一个人 + 4 个 AI Agent + 一件代发（Dropshipping）+ 多平台矩阵，跑通"选品→内容→运营→风控"全链路自动化。

1.2 核心假设

  • 行业窗口期还在：跨境电商全球规模 2025 年突破 1.5 万亿美金，AI 工具渗透率 < 15%，OPC 模式渗透率 < 5%
  • AI 杠杆真实存在：选品/内容/运营/风控 4 个环节，AI Agent 可替代 60-80% 人工
  • OPC 比小团队更优：决策速度快、试错成本低、不用人头管理，可并行测试多个平台/品类
  • 跳过亚马逊是合理选择：平台规则严、广告成本高、新人友好度差，不适合 OPC

1.3 三个差异化优势

  1. OpenClaw 多智能体底座：自研 AI Agent 平台（dogfooding），可控可迭代，比 SaaS 工具更灵活
  2. OPC 专属知识库：把每次选品/运营/复盘的经验结构化沉淀，AI 持续调用，形成自我增强的飞轮
  3. 跨平台矩阵策略：不押注单一平台，多平台分散风险，单平台规则变化不致命

SKU 上限30-50100-300

真实天花板月销 5-15 万美金月销 10-30 万美金

2.2 OPC 的真正护城河

不是"用 AI"，而是 "AI 工作流 + 专属知识库"。任何人都能用 ChatGPT 生成文案，但只有你能让 AI Agent 自动调用你的私有知识库做决策。

护城河 = 知识库沉淀深度 × AI Agent 工作流自动化程度 × 跨平台数据闭环

3.2 平台路径图（12 个月）

  • Month 1-2：Temu 半托管 + AliExpress 双平台试跑，验证供应链和 SOP
  • Month 3-4：加入 TikTok Shop，验证内容驱动型品类
  • Month 5-6：单平台单品类稳定盈利，建立可复制 SOP

3.3 平台选择核心原则

  • 规则谁说了算：选规则透明、可预测的平台（避开政策黑盒的亚马逊）
  • 退出成本多大：选沉没成本低的平台（先 Temu 半托管，1688 一件代发零库存）

4.3 工具栈选型

CHAPTER 05

选品与运营策略

5.1 选品三阶段

阶段 1：跟卖验证（Month 1-2）

  • 目标：跑通 SOP，验证供应链
  • 方法：从 Temu/AliExpress 爆品里挑，单 SKU 上架时间 ≤ 24h
  • KPI：上架成功率 100%、测款成功率 20%、单 SKU 日销 ≥ 3 单
  • 预算：单 SKU 测试广告预算 ≤ 50 美金

阶段 2：微创新（Month 3-6）

  • 目标：建立差异化壁垒
  • 方法：在爆品基础上做颜色/包装/配件/场景差异化，配合 AI 生成新素材
  • KPI：自有 listing 占比 ≥ 30%、毛利率 ≥ 35%、退货率 ≤ 5%
  • 预算：单 SKU 测试预算 ≤ 200 美金

阶段 3：自有品牌（Month 6+）

  • 目标：建立真正的护城河
  • 方法：沉淀数据后做真正有壁垒的产品，注册商标，做品牌故事
  • KPI：品牌词搜索量、复购率 ≥ 15%、客单价提升 30%+
  • 预算：根据前两阶段利润滚动投入

5.2 选品硬规则（永不违反）

✓ DO
  • 毛利率 ≥ 30%
  • 售价 ≥ 15 美金
  • 重量 ≤ 1kg（物流可控）
  • 1688 同款 ≥ 3 个供应商
  • 平台政策友好
  • 商标/专利清晰
  • 退货率预估 ≤ 8%
✗ DON'T
  • 毛利率 < 25% 直接放弃
  • 售价 < 10 美金（广告撑不住）
  • 重量 > 2kg 或抛货
  • 单一供应商依赖
  • 任何平台禁售/限售品类
  • 已注册商标/有专利纠纷的品
  • 高退货率品类（服装鞋帽慎入）

5.3 运营节奏

  • 每日：4 Agent 自动巡检，异常推送给主理人
  • 每周：运营 Agent 输出周报，主理人 30 分钟 review
  • 每月：选品 Agent + 运营 Agent 联合输出月度复盘，调整 SOP
  • 每季度：战略复盘，决定是否切换平台/品类
CHAPTER 06

知识库建设路径

6.1 知识库是真正的资产

不是 AI 模型，不是 Agent 工作流，是沉淀下来的结构化经验。

6.2 知识库结构

/knowledge-base/
├── /products/           # 商品库
│   ├── /winning/        # 跑赢的品（含所有数据）
│   ├── /failed/         # 跑输的品 + 死因分析
│   └── /archived/       # 阶段性淘汰的品
├── /suppliers/          # 供应商库
│   ├── /primary/        # 主供应商
│   ├── /backup/         # 备用供应商
│   └── /blacklist/      # 黑名单供应商
├── /platforms/          # 平台规则库
│   ├── /temu/
│   ├── /tiktok-shop/
│   └── /aliexpress/
├── /compliance/         # 合规知识库
│   ├── /trademarks/     # 商标抢注预警
│   ├── /patents/        # 专利黑名单
│   └── /policies/       # 各平台政策更新
├── /decisions/          # 决策日志
│   ├── /selection/      # 选品决策记录
│   └── /strategy/       # 战略决策记录
└── /playbooks/          # SOP 文档
    ├── /testing/
    ├── /scaling/
    └── /exiting/

6.3 知识库积累机制

  1. 每次决策自动写入：4 Agent 的所有决策都要记录"决策依据 + 结果 + 复盘"
  2. 每月人工 review：主理人 review 知识库，更新判断模型
  3. 每周 AI 自动提炼：OpenClaw Agent 自动从日志中提炼模式，更新 SOP
  4. 季度战略复盘：基于知识库生成下季度战略建议

6.4 知识库的 AI 调用接口

def selection_agent(candidate_product):
    # 1. 检索相似品历史
    similar = knowledge.search_similar(candidate_product)

    # 2. 检索失败案例
    failures = knowledge.get_failure_patterns(candidate_product.category)

    # 3. 检索供应商
    suppliers = knowledge.get_suppliers(candidate_product.supplier_id)

    # 4. 综合判断
    decision = llm.reason({
        "candidate": candidate_product,
        "similar_history": similar,
        "failure_patterns": failures,
        "supplier_reliability": suppliers
    })

    # 5. 决策记录入库
    knowledge.log_decision(candidate_product, decision)

    return decision

CHAPTER 08

风险地图与应对

8.1 致命风险（一旦发生 = 项目死亡）

R1 致命 账号被封

  • 触发：多账号关联、违规操作、平台审查、二审失败
  • 影响：全部资产归零，账号申诉期 30-90 天
  • 预防：
    • 1 人 1 平台 1 账号 1 设备 1 网络 1 支付
    • 养号期 2 周只看不买
    • 风控 Agent 每日巡检账号健康度
    • 平台政策变化 24h 内同步到知识库

R2 致命 合规暴雷

  • 触发：商标抢注、专利侵权、VAT 漏报、平台政策违规
  • 影响：listing 下架、资金冻结、法律诉讼
  • 预防：
    • 上架前风控 Agent 自动扫描 USPTO/EUIPO 商标库
    • 外观专利排查（重点品类：家居/3C/服装）
    • 欧洲销售超过阈值启动 VAT 注册
    • AI 生成内容版权溯源（标注 prompt + 来源）

R3 致命 现金流断裂

  • 触发：广告 ROI 持续亏损、库存积压、平台账期延长
  • 影响：无法继续运营
  • 预防：
    • 前 3 个月纯一件代发零库存
    • 运营 Agent 实时监控 ROI，>3 天亏损自动暂停
    • 平台账期 + 广告预充 + 退货扣款合并现金流预测
    • 月度现金流 review，红线即停

8.2 高风险（影响 30-50% 收入）

R4 高 广告费烧光

  • 新手最常犯的错
  • 测款期单 SKU 预算 ≤ 50 美金
  • 跑不出自然单立即放弃
  • 运营 Agent 自动调整出价

R5 高 库存积压

  • 一件代发理论上零库存，但批量备货易积压
  • 前 3 个月纯一件代发，第 4 个月起才考虑备货 30 天销量
  • 选品 Agent 拒绝任何需要备货 > 100 件的品

R6 高 供应链断裂

  • 1688 卖家突然涨价/断货/失联
  • 每个 SKU 必须有 2 个以上备用供应商
  • AI Agent 自动监控价格和库存波动

8.3 中风险（影响 10-30% 收入）

  • R7 平台政策变化：多平台矩阵分散风险
  • R8 汇率波动：AI Agent 每日同步汇率，调整定价
  • R9 物流时效：选品 Agent 拒绝头程 > 15 天的品
  • R10 差评累积：AI 客服 Agent 自动响应 + 主动 follow-up

8.4 第 6 个月生存铁律

优先级排序：

  1. 账号安全（永远第一）
  2. 现金流（永远第二）
  3. 利润（长期目标）
  4. GMV（最不重要）
任何决策都要回答：这个动作会不会威胁到账号？会不会威胁到现金流？

CHAPTER 11

退出与规模化路径

11.1 退出条件（红灯信号）

连续 3 个月出现以下任一情况，建议暂停或转向：

  • 月销增长 < 10%
  • 毛利率 < 20%
  • 退货率 > 10%
  • 账号被警告 ≥ 2 次

11.2 规模化路径（Phase 5+）

A · 产品化

把 OpenClaw 跨境 Agent 工作流产品化，卖给其他 OPC。

B · 团队化

招 2-3 个运营，复制 OPC 模式到 3-5 个品类。

C · M&A

项目被跨境电商 SaaS 或品牌商收购。

D · IP 化

沉淀为跨境电商培训/咨询服务。
